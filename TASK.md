# REELINATOR — задание на разработку

Создай на основе [skailabinfo/claude-video-harness](https://github.com/skailabinfo/claude-video-harness) универсальный репозиторий для **создания и монтажа видео через Codex и Claude Code**. Сохрани полезную основу, устрани подтверждённые ограничения и доведи систему до работающих результатов.

Пользователь ставит задачу свободным языком: может дать видео, голос, изображения, сценарий, ссылку, референс либо одну идею. Система выполняет запрошенный объём — анализ, монтаж, создание с нуля или конкретную правку. Формат, длительность, стиль, язык и звук определяются задачей.

## Возможности

- **Монтаж:** выбор дублей и фрагментов, склейки, изменение ритма, кадрирование, композиция, титры, субтитры, переходы и обработка звука.
- **Создание с нуля:** программные сцены, анимированная инфографика, интерфейсы, 2D-графика и подходящие 3D-вставки, включая видео без исходной съёмки и озвучки.
- **Работа по референсу:** анализ доступного образца и применение выбранных монтажных или визуальных приёмов.
- **Итерации:** быстрые превью и правки обычными словами с сохранением остальных принятых решений.
- **Результат:** качественный видеофайл и воспроизводимый редактируемый проект, который можно открыть и продолжить в обеих агентских средах.

## Реализация

Основной стек — **Remotion + FFmpeg** из исходного репозитория. Используй существующие компоненты, команды и форматы данных, прежде чем вводить новые абстракции. Для каждого видео обеспечь изоляцию исходников, состояния, кэша и результатов. Правки сохраняются в источнике повторной сборки; ошибки не уничтожают принятый результат.

Выбор средств уже исследован. Прочитай **`TECH_DECISIONS.md` при первоначальном проектировании**, затем обращайся к нужным разделам при реализации соответствующих возможностей. Применяй отобранные приёмы и проверенные улучшения; устанавливай дополнительные зависимости под конкретную задачу. В `prework/` лежит ранее проверенный патч обработки звука — оцени его применимость к текущему коду.

Сделай единый набор рабочих операций, вызываемых как из Codex, так и из Claude Code. **`AGENTS.md` — общий источник проектных инструкций; `CLAUDE.md` содержит только `@AGENTS.md`.** Адаптируй унаследованные инструкции и навыки под эту схему. Постоянный контекст оставь минимальным: назначение, подтверждённые команды и особенности, которые нельзя надёжно вывести из кода. Следуй принципам [Anthropic о контекстной инженерии](https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models): автономность модели, ясные инструменты, контекст по необходимости и проверка пользы каждой инструкции.

## Приёмка

Покажи работающие сквозные примеры:

1. Монтаж реальной речи: аккуратная нарезка, синхронные субтитры, качественный звук.
2. Видео по одной текстовой идее: оригинальная анимированная графика, без исходного видео.
3. Правка существующего проекта по свободному запросу: повторная сборка сохраняет внесённые изменения и остальные сцены.
4. Продолжение одного проекта в Codex и Claude Code на общих файлах и командах; фактическую проверку каждой среды явно отметь.

Для примеров сохрани готовое видео/превью, проект и результаты проверок: воспроизведение, синхронизация, текст, звук и корректность правок. В `README.md` опиши реально работающие запуск, монтаж, правку и экспорт.

Начни с работающего прохода исходной базы; затем исправь препятствия универсальному монтажу и последовательно реализуй возможности выше. **Итог — рабочий REELINATOR с проверенными видео, а не только документация или демонстрационные заготовки.**
