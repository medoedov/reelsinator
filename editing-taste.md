# Монтажные предпочтения

Предпочтения хранятся у выбранного аккаунта в `video/accounts/<account>/`.
Прочитай его `SOURCE.md` и только нужные по задаче ссылки. Аккаунт существующего
ролика указан в `project.json.account`; правила — [docs/accounts.md](docs/accounts.md).

Этот файл оставлен для старых ссылок. Общих монтажных предпочтений для всех аккаунтов нет.
