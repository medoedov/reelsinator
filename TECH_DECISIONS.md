# REELINATOR — технические решения

Справочник для разработки сцен и общих операций. Дополнительные зависимости
подключаются под конкретную задачу, а не при каждом запуске.

## Основной стек

| Задача | Средство и назначение |
|---|---|
| Редактируемые сцены и рендер | Remotion, React и TypeScript; анимация вычисляется из номера кадра |
| Подготовка медиа | FFmpeg/ffprobe: нарезка, скорость, кадрирование, PCM-аудио и проверка результата |
| Общий интерфейс | `python reel.py`: одинаковые операции из Codex и Claude Code |
| Распознавание речи | Необязательный локальный whisper.cpp; исправленный `transcript.json` можно подготовить вручную |
| Видеореференсы | FFmpeg для измерений и контактного листа; yt-dlp для доступных URL |
| Финальный звук | Один PCM-проход, двухпроходный loudnorm, однократный AAC 48 кГц и faststart |

## Контракты проекта

- Один ролик хранится в `video/projects/<id>/`; исходники, настройки, кэш и результаты изолированы.
- TSX и JSON являются источником повторной сборки. Изменение только готового MP4 не сохраняет монтаж.
- `edit.json` задаёт интервалы исходника; слова в `transcript.json` используют исходное время.
- `prepare` создаёт производные медиа и пересчитывает субтитры. Кэш зависит от содержимого и параметров.
- `out/latest.json` обновляется после успешного экспорта и проверок; ошибка сохраняет предыдущий результат.
- Техническая проверка файла не заменяет просмотр, прослушивание и проверку смысла монтажных стыков.

## Подключать по необходимости

Изометрические схемы и 2D-графика могут создаваться в SVG/React. Для сцен, которым нужна
настоящая трёхмерная геометрия, можно подключить Three.js через Remotion Three.
Маттинг нужен только сценам с отделением человека от фона. Эти дополнительные возможности
пока не входят в набор проверенных сквозных примеров.

Сначала выбираются сценарий и визуальное решение, затем необходимые инструменты.
Ритм речи, цельные слова, читаемые подписи и осмысленные звуковые акценты проверяются
на конкретном ролике. Автоматическое сжатие пауз остаётся черновой монтажной операцией.

## Инструкции агентов

`AGENTS.md` — общий источник инструкций. `CLAUDE.md` содержит только `@AGENTS.md`.
Канонические навыки хранятся в `skills/`; `python scripts/sync-skills.py` обновляет
их копии в `.agents/skills/` и `.claude/skills/`. Подробные операции описаны
в [рабочем руководстве](docs/workflow.md), результаты проверок — в [отчёте](examples/ACCEPTANCE.md).
