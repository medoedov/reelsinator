# Настройка

Прочитай корневой `AGENTS.md` и выясни по запросу, требуется окружение, стиль выбранного
ролика или конкретный сервис. Выполняй только этот объём.

Для окружения запусти `python reel.py doctor`. Недостающие обязательные инструменты и запуск
описаны в корневом `README.md`. ASR, загрузчик ссылок, маттинг и генеративные сервисы нужны
только задачам, которые их используют; для программной анимации они не являются условиями запуска.

Для стиля используй заданный бренд, референс и предпочтения. Сохраняй палитру и параметры
выбранного ролика в его `project.json`, сценические решения — в `Composition.tsx`.
Если есть существенный нерешённый выбор, покажи вариант кадром через `python reel.py still <id>`.
Не превращай локальную настройку в обязательное интервью о всех возможностях.

Подключение внешнего сервиса не следует из настройки стиля. Для запрошенного сервиса проверь
актуальный способ доступа и стоимость; ключи остаются в локальном окружении. Не печатай их
и не сохраняй в исходниках. Платная генерация требует разрешения на конкретный расход.
