# Работа с видеопроектом

Команды ниже запускаются из корня репозитория. `python3` подходит там, где он заменяет
`python`. Свободный запрос интерпретирует Codex или Claude Code: агент редактирует обычные
TSX/JSON, а `reel.py` выполняет конкретные операции. CLI не является отдельным языковым агентом.

## Файлы одного ролика

| Файл | Назначение |
|---|---|
| `video/projects/<id>/project.json` | Название, идея, размер, fps, длительность графики, палитра, шрифт, цель громкости |
| `Composition.tsx` | Редактируемые сцены, их порядок, анимация, изображения и звук |
| `index.tsx` | Регистрация композиции `Reel`; длительность подготовленного монтажа имеет приоритет над длительностью графики |
| `public/assets/` | Импортированные исходники, имена по SHA-256; каждый проект хранит собственные файлы |
| `edit.json` | Исходник и сохраняемые интервалы исходного времени, скорость и способ кадрирования |
| `transcript.json` | Исправленный текст со временем слов в исходной записи |
| `media.json` | Вычисленные пути видео/PCM-звука, субтитры на смонтированной шкале и кадры склеек |
| `public/prepared/`, `cache/` | Производные медиа и временные файлы; результат связан с содержимым исходника и параметрами |
| `out/runs/<run>/` | Успешный мастер, превью, проверки, журнал и снимок исходного кода сборки |
| `out/latest.json` | Указатель на последнюю успешно проверенную версию экспорта |

Сохраняй исходные медиа вместе с проектом: снимок кода в экспорте не заменяет большие файлы
из `public/assets/`. При продолжении в другой среде используются те же файлы и команды.

## Новый ролик из идеи

```sh
python reel.py new my-film --title "Новая история" --idea "Как рождается идея" --width 1280 --height 720 --fps 30 --seconds 12
python reel.py studio my-film
```

Команда создаёт рабочую стартовую композицию. Разработай сцены в её `Composition.tsx` под
конкретную идею: сам по себе параметр `--idea` не пишет новый сценарий и анимацию.
Стиль и формат примера `idea-to-film` не являются обязательным стилем остальных видео.
Анимация без речи может оставаться без озвучки; не запускай для неё распознавание или маттинг.

## Монтаж записи

Сначала осмотри исходник и прослушай речь. Выбирай целые связные дубли по смыслу и исполнению;
последний повтор не всегда лучший. Концы слов, вдохи и намеренные паузы важнее количества склеек.

```sh
python reel.py new interview --width 1080 --height 1920
python reel.py cut interview --source "C:/media/take.mov" --keep "0.2:5.1,7.0:12.4" --fit cover
```

`--keep` задаёт упорядоченные непересекающиеся интервалы исходника в секундах. Без `--keep`
сохраняется весь исходник. `--fit contain` сохраняет весь кадр с полями, `cover` заполняет кадр
с обрезкой; проверяй лицо и нужные детали. `--speed` меняет скорость видео и звука совместно.

`--auto` вместо `--keep` создаёт черновое сжатие длинных пауз с уточнением по уровню звука.
Оно не распознаёт повторы, оговорки или смысл. Прослушай стыки и скорректируй `edit.json`.
Затем `python reel.py prepare interview` повторяет подготовку по сохранённым решениям.
Отдельная аудиозапись также подходит в качестве `--source`; видеоряд в этом случае задаётся TSX.

Для локального распознавания нужны `whisper-cli` и файл многоязычной модели:

```sh
python reel.py transcribe interview --language ru --model "C:/models/ggml-model.bin"
```

Можно задать `WHISPER_MODEL` вместо `--model`. Установка ASR не требуется, если расшифровка
уже есть: запиши её в `transcript.json` в формате
`[{"w":"Слово","s":0.45,"e":0.82,"em":1}]`. `s` и `e` относятся к исходнику, не к нарезке.
Исправляй текст и тайминги в этом файле. Повторное распознавание непустого файла требует
`--replace`, поскольку оно заменяет ручные исправления.

`prepare` пересчитывает субтитры из исходного времени в монтажное. Если склейка пересекает
слово по расшифровке, подготовка останавливается: проверь запись, границу или ошибочный тайминг.
`media.json` вручную не правится. Сверь русские слова, имена и английские названия на слух;
прохождение автоматической проверки файла не доказывает точность ASR.

## Сцены, графика и звук

Компоненты `MediaLayer`, `CaptionTrack`, `Fade` находятся в `video/src/project/`.
`video/src/ui/` сохраняет панели, карточки, рисунки и приёмы раскрытия исходного harness.
Параметры нового ролика локальны; часть унаследованных компонентов читает глобальный
`harness.config.json`, поэтому проверь зависимости перед использованием их в своём проекте.

Используй `Sequence` для расположения TSX-сцен на шкале, `useCurrentFrame()` для движения
и `useVideoConfig()` для размера/fps. Внутри `Sequence` кадр локальный. `CaptionTrack` принимает
подготовленные слова и поддерживает верхнее, нижнее или центральное расположение: выбирай
позицию по содержимому кадра, чтобы не закрывать лицо, интерфейс или важную графику.

`python reel.py import my-film "C:/media/image.png"` копирует файл в проект и выводит путь
внутри `public/`. Подключи его через `staticFile()` в `Img`, `OffthreadVideo` или `Audio`.
Так можно добавлять изображения, дополнительные планы, музыку и эффекты; положение,
обрезка, переходы и уровни остаются в TSX. Для монтажного исходника используй `cut`.

Для звуковых акцентов сохрани в проекте короткий cue sheet: файл, происхождение/разрешение,
время, уровень и назначение. Слушай их вместе с речью; визуальный акцент и звук должны
восприниматься как одно событие. Мастер смешивается из целого PCM-прохода, нормализуется
двумя проходами loudnorm и кодируется в AAC один раз; тишина обрабатывается отдельно.
Платная генерация, чужие ассеты и публикация требуют соответствующего разрешения.

## Референс

```sh
python reel.py reference my-film "C:/media/reference.mp4"
python reel.py reference my-film "https://example.com/watch/video"
```

Для URL нужен `yt-dlp`; доступность конкретного источника проверяется фактической загрузкой.
Результат находится в `cache/references/`: контактный лист, кандидаты смены планов,
длительность и SHA-256. URL и содержимое участвуют в идентификации; порядковый номер не
используется как личность ролика. Ошибка внешней команды останавливает анализ.

Посмотри контактный лист и нужные фрагменты: измеренная смена картинки может оказаться
движением камеры, а не склейкой. Опиши выбранные приёмы — ритм, крупность, типографику,
композицию, переходы — и перенеси их в собственные сцены. Доступ к референсу не означает
разрешения вставлять его кадры или звук в готовый ролик.

## Правка и проверка

При запросе «измени финальный заголовок» правь соответствующую сцену, при запросе «убери
фразу» — интервалы `edit.json`, при исправлении субтитра — `transcript.json`.
Не применяй правку только к готовому MP4: следующая сборка должна её воспроизводить.

```sh
python reel.py still my-film --frame 60
python reel.py preview my-film
python reel.py render my-film --concurrency 2
python reel.py verify my-film
```

Сравни изменённый участок и несколько неизменённых сцен, проверь последний кадр,
читаемость текста, субтитры и синхронизацию, прослушай звук. Сохрани результаты проверки
рядом с экспортом, разделяя автоматические измерения, просмотр и прослушивание.

`preview` создаёт быстрый черновик в половинном разрешении в `cache/` одним проходом,
без финального мастеринга. Он не заменяет принятую версию в `out/latest.json`.

`render` создаёт отдельную версию только после декодирования файла и проверки кадров,
формата, синхронизации потоков и faststart. Старый экспорт остаётся доступным при ошибке.
`checks.json` сохраняет технические измерения и хэши исходников; поля визуальной/речевой
проверки со значением `pending` не являются подтверждением качества.

Для передачи проекта между Codex и Claude Code достаточно общего каталога. Укажи, какая
среда реально открыла проект, выполнила правку и команду, а какая ещё не проверена.
Успешная сборка в одной среде не доказывает фактический запуск другой.
