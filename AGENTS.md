# REELINATOR

Создание и монтаж видео через Codex и Claude Code: Remotion + FFmpeg, обычные TSX и JSON.
Выполняй объём текущего запроса: анализ, новый ролик или конкретную правку. Формат, стиль,
длительность, язык и звук определяются задачей; настройка профиля не блокирует работу.

## Рабочие файлы

- Один ролик — `video/projects/<id>/`: `Composition.tsx`, `project.json`, исходники в `public/`.
- `edit.json` хранит интервалы исходной записи; `transcript.json` — исправленный текст и
  тайминги исходника. `media.json` и `public/prepared/` вычисляются командой `prepare`.
- Правь источник повторной сборки, затем рендери. Изменение только готового MP4 не сохраняет монтаж.
- Для продолжения открой файлы выбранного проекта и `out/latest.json`; обе среды используют их напрямую.
- `video/src/project/` — общие компоненты; `video/src/ui/` — библиотека графических элементов.
  `video/src/Composition.tsx` и глобальный `harness.config.json` относятся к отдельному демо.

## Команды из корня

```sh
python reel.py doctor
python reel.py list
python reel.py new <id> --idea "идея" --width 1280 --height 720 --seconds 12
python reel.py still <id> --frame 60
python reel.py studio <id>
python reel.py render <id>
python reel.py verify <id>
```

Если в системе интерпретатор называется `python3`, замени `python`. Параметры операций:
`python reel.py <command> --help`. Монтаж, ASR, референсы и устройство проекта —
`docs/workflow.md`; технические решения для конкретной возможности — `TECH_DECISIONS.md`.

## Особенности

- Анимации вычисляются из кадра Remotion: рендер может запрашивать кадры не по порядку.
- `render` публикует новую версию в `out/runs/` и меняет `out/latest.json` только после проверок.
  Ошибка не делает предыдущий экспорт устаревшим или неуспешным. Не выбирай результат по наличию MP4.
- Субтитры и склейки проверяй по речи; автоматическое сжатие пауз — черновик. Маттинг нужен
  только сценам с вырезкой человека. Графика без речи не требует ASR или внешних сервисов.
- Фактические проверки изображения, прослушивания и агентских сред отмечай отдельно от
  автоматических проверок файла. Не выдавай запуск CLI за проверку качества реальной речи.
- Инструкции проекта редактируются здесь; `CLAUDE.md` содержит только `@AGENTS.md`.
  Канонические навыки — `skills/`; `python scripts/sync-skills.py` обновляет одинаковые копии
  в `.claude/skills/` и `.agents/skills/`, `--check` проверяет совпадение.
